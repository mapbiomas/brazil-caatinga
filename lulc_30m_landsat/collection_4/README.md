## Estrutura do diretório


1. Na pasta principal haverá pastas para os pequenos projetos realizados dentro da empresa.
2. Dentro da pasta dos pequenos projetos, pastas com as tecnologias usadas, por exemplo: javascriptEE ou python
3. Os arquivos deve ser normeados com nomes relevantes, separados por '\_' e com terminologia da tecnologia, por exemplo: salva\_imagem\_do\_arquivo.js

## Avisos 

1. É sempre importante atualizar o respositório antes de mexer nos arquivos (git fetch e git pull).
2. Evitem os conflitos.
3. Caso haja conflitos, resolvam os conflitos.
